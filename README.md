# Life Admin (Android)

A small Android app with the Life Admin logo. Opening it shows Darren's Life Admin page
(https://claude.ai/artifact/37YJK3ing21Rw7bVb3PY54) in a Chrome tab, so it uses his existing
Claude login and Google connections. Built by GitHub Actions on every push; the latest APK is
on the Releases page (tag `latest`).
